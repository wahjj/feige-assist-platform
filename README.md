# 飞鸽只读 AI 辅助中台 Demo

本项目是一套单服装商家的本地辅助中台演示。商家仍使用抖店飞鸽原生工作台接待买家，中台只接收同步消息、展示只读业务镜像，并生成可供人工审核复制的 RAG AI 建议。

中台不发送买家消息，不接管会话，不修改商品、订单或库存。

## 启动

在 Windows 上双击 `start.bat`，浏览器会打开：

`http://127.0.0.1:8000/login`

演示账号：

- 用户名：`admin`
- 密码：`admin123`

当前服务只监听本机地址。

## 已实现

- Vue 3 独立中台页面和纯本地 SQLite 数据。
- 商品 + 多 SKU 只读镜像。
- 买家/客服消息会话镜像，支持“完整”和“仅买家消息”标识。
- 订单、物流与售后状态只读查询。
- 客户历史订单、历史会话、本地标签和跟进备注。
- 服装知识库：尺码、面料、养护、搭配、售后与 FAQ。
- 本地关键词/全文 RAG 召回。
- OpenAI 兼容真实模型配置和连接测试。
- 三条 AI 建议、知识来源、敏感词拦截和复制统计。
- 模拟抖店 OAuth、Webhook 和商品/订单手动拉取。
- 模拟飞鸽事件页面。
- 业务分析。
- `/panel` 飞鸽侧栏占位。

## 页面入口

- `/`：中台概览
- `/conversations`：只读会话中心与 AI 建议
- `/products`：商品与 SKU
- `/orders`：订单查询
- `/customers`：客户档案
- `/knowledge`：AI 知识库
- `/analytics`：业务分析
- `/sync`：同步与大模型设置
- `/mock-events`：模拟飞鸽事件
- `/panel`：飞鸽侧栏占位，不包含实际面板功能

## 模拟验收

1. 登录后进入“同步与设置”，确认抖店连接为 `demo_connected`。
2. 点击手动拉取商品和订单，确认只读镜像更新时间变化。
3. 进入“模拟飞鸽事件”，选择尺码咨询并发送。
4. 在“会话中心”查看新买家消息和完整性标记。
5. 如需 AI 建议，在设置中填写 OpenAI 兼容服务地址、模型名称和 API Key。
6. 模型配置后，新买家消息自动生成一次建议，也可点击重新生成。
7. 点击“复制话术”会在分析中记录复制次数，但不会向买家发送。
8. `/panel` 仅展示预留说明。

## 真实接入边界

当前阶段全部使用本地模拟事件，不调用真实抖音接口。真实接入后续需要：

- 商家在抖店开放平台创建自研自用应用。
- 获批飞鸽消息和会话状态相关权限。
- 提供公网 HTTPS Webhook 地址。
- 完成 OAuth、签名验证和商品/订单补偿拉取。

具体权限名称、字段和签名方式必须以最终开放平台文档和审批结果为准。

## Demo 限制

- 不执行真实退款、补偿或补发。
- 不提供飞鸽消息发送接口。
- 不使用向量数据库，当前为本地关键词/全文召回。
- 当前仅支持单管理员。
- 飞鸽右侧自研面板尚未实现。
